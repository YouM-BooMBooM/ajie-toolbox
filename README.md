# 阿杰工具箱 0.6.0

抖音直播批量录制 + 评论收集 + 话术提取（本地运行，不上传任何数据）。

## 下载

到 [Releases](../../releases/latest) 下载 `AJ-Toolbox-*-green.zip`：

1. 解压到任意目录（不要放 C:\Program Files）
2. 双击 `安装.bat`（建桌面快捷方式）
3. 首次打开若提示缺模型，到「话术提取」页点「一键下载模型」

## 系统要求

- Windows 10/11 64 位
- 录制需要能访问抖音（建议稳定网络）
- 话术提取建议有 NVIDIA 显卡（6GB 显存以上），没有也能用 CPU 但慢
